# HADI Telegram Video Bot — تعليمات بالعربي

## ما الذي يفعله؟
- يستقبل رابط فيديو عام ويحاول تنزيله عبر yt-dlp.
- يحاول اختيار أفضل صيغة متاحة ضمن حد حجم الإرسال المضبوط.
- يدعم عدداً كبيراً من المواقع التي يدعمها yt-dlp، لكن دعم كل موقع/رابط غير مضمون وقد يتغير.
- لا يتجاوز DRM أو تسجيل الدخول أو الفيديوهات الخاصة، ولا يزيل العلامة المائية من الفيديو؛ يرسل النسخة التي يوفرها الموقع.

## قبل البدء
1. أنشئ بوتاً من `@BotFather` عبر `/newbot` وخذ التوكن.
2. لا ترسل التوكن لأي شخص ولا تضعه داخل `bot.py` أو مستودع GitHub عام.
3. أنشئ حساب GitHub من متصفح Samsung إذا ما عندك حساب.

## رفع الملفات من الموبايل
1. فك ضغط ZIP على هاتفك.
2. أنشئ مستودع GitHub جديداً باسم `hadi-telegram-video-bot`.
3. ارفع `bot.py` و`requirements.txt` و`Dockerfile` و`.env.example` و`README_AR.md` إلى المستودع. لا ترفع ملفاً يحتوي توكنك الحقيقي.
4. افتح منصة استضافة تدعم النشر من GitHub وDockerfile، واربطها بالمستودع.
5. أضف متغير البيئة `TELEGRAM_BOT_TOKEN` في إعدادات الخدمة، وقيمته التوكن من BotFather.
6. اختر خطة تشغيل مستمرة (Always-on / paid worker). لا تستخدم خطة تنام أو تتوقف إذا تريد البوت 24/7.
7. انشر الخدمة. إذا ظهرت أخطاء، افتح Logs واقرأ أول خطأ أحمر.

## إعداد الاستضافة
- هذا مشروع عامل خلفي (worker)، وليس موقع ويب؛ لا يحتاج نطاقاً أو صفحة ويب.
- يجب أن تشغّل الاستضافة الأمر الموجود في Dockerfile: `python bot.py`.
- لا تضف `PORT` أو إعدادات web server إلا إذا طلبتها المنصة.
- حد الإرسال الافتراضي مضبوط على 48 MB لتقليل فشل الإرسال من Telegram Bot API. تغييره لا يضمن قبول Telegram للملفات الأكبر.
- أفضل جودة لا تعني دائماً 4K: يعتمد ذلك على ما يتيحه الموقع، وعلى حجم الملف وحدود Telegram. الكود الحالي يفضّل أفضل ملف متاح ضمن الحد، لكنه لا يضمن أعلى دقة مطلقة لكل موقع.

## اختبار التشغيل
1. افتح رابط البوت في Telegram واضغط Start.
2. جرّب رابطاً عاماً تملكه أو لديك إذن بتنزيله.
3. اختبر كل موقع على حدة. احتفظ برابط اختبار لكل منصة، لأن الدعم يتغير مع تحديثات المواقع وyt-dlp.
4. إذا فشل موقع، حدّث `yt-dlp` من خلال إعادة النشر بعد تحديث `requirements.txt` أو أخبرني برسالة الخطأ من Logs (بدون التوكن).

## ملاحظات تشغيلية
- إذا انتهت الخدمة أو وصلت حدود الذاكرة/التخزين، قد يفشل التنزيل.
- لا تستخدم البوت لتنزيل محتوى لا تملك حق تنزيله.
